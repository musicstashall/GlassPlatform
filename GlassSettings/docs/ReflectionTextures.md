# Текстурные отражения

Коллекция `Resources/GlassReflection` разделена на `Textured` (плитки) и
`Pattern` (цельные изображения). Старые изображения непосредственно в корне
по-прежнему поддерживаются. Каталог `Tests` не включается в UI.
Имена исходников должны быть уникальны среди текстур; размеры в именах не нужны.

## Подготовленные узоры

- `FrostGrain`: прежний GlassReflection_01, увеличение 120%.
- `CrystalWeave`: прежний GlassReflection_02, увеличение 146%.

Увеличение выполнено nearest-neighbor, чтобы сохранить дискретное зерно.
Из центра увеличенной альфа-маски взят сегмент 128×128; зеркальное продолжение
по обеим осям формирует бесшовную плитку 256×256. Это намеренно меняет расположение
зерна, но сохраняет его масштаб. Dark — чёрный RGB, Lite — белый, альфа одинаковая.

## Применение

`ReflectionTextureService` собирает PNG точным копированием пикселей плитки.
Краевые неполные плитки обрезаются. Размер берётся из SM_CXVIRTUALSCREEN /
SM_CYVIRTUALSCREEN, поскольку OpenGlass масштабирует отражение на виртуальный стол.
PNG сохраняется в `%LOCALAPPDATA%/GlassPlatform/GlassReflection/<ширина>x<высота>/`
под исходным именем. Соседний `.sha256` хранит хеш источника и версию алгоритма.
Запись PNG производится через временный файл и замену; путь применяется только
после завершения генерации. Ограничения размера соответствуют проверкам PNG
upstream OpenGlass (16384 по стороне, 33554432 пикселя).

Генерация сериализована, заполнение полотна выполняется вне UI-потока.
Операция выбора проходит через page operation pipeline. Для выделения и защиты
активного исходника от удаления путь к кэшу сопоставляется с Textured по имени.
Произвольные PNG вне каталога кэша так не сопоставляются.

## Текущее ограничение

Размер экрана проверяется при выборе текстуры. Автоматическое переприменение
после изменения конфигурации мониторов, без повторного выбора пользователем,
пока не подключено. Пересборка и runtime-проверка WinUI требуют Windows.
