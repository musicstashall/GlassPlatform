# Порядок в репозитории

Репозиторий — исходники, сборка и документация. Ассистент **не** оставляет следы работы в дереве проекта.

## Куда класть файлы

| Назначение | Путь |
|------------|------|
| Исходники, проекты, документация | `GlassCore/`, `WndCompat/`, README и `docs/` в каталогах проектов, корень solution |
| Бэкапы перед правками | `_backups/<YYYY-MM-DD_HHMM>/` |
| **Разовые скрипты ассистента** | **`.claude/tmp/`** |
| Постоянные утилиты репозитория | `tools/`, `scripts/` (по задаче пользователя) |
| Скрипт вне репо | `%TEMP%` / `$env:TEMP` |

## Обязательно для ассистента

1. **Не** создавать `_tmp*.py`, `write_*.py`, `.ps1` в **корне** `GlassProject/`, в `GlassCore/`, `WndCompat/`, `.cursor/skills/` и т.п.
2. Разовый скрипт в репо — только `.claude/tmp/` (имя вроде `fix-encoding-2026-06-01.py`).
3. **Сразу после** выполнения — **удалить** скрипт и все временные артефакты, которые он создал.
4. В итоге задачи указать, что временные файлы удалены (если создавались).
5. Не коммитить разовые скрипты.

## Пример

```bat
mkdir .claude\tmp 2>nul
python .claude\tmp\convert-md-utf8.py
del .claude\tmp\convert-md-utf8.py
```

Или однострочный `python -c "..."` без файла в репо.

## Чего не делать

- Оставлять скрипты в корне или рядом с исходниками.
- Дублировать утилиты в `tools/` без запроса.
- Создавать вспомогательные файлы в `.cursor/skills/` (там только `SKILL.md`).
