# Черновик GitHub Wiki

Черновик страниц для вики репозитория. В репозитории вики **включена**
(`Settings → Features → Wikis`), но файлов в ней ещё нет: пока не создана первая
страница, GitHub не поднимает git-репозиторий `GlassPlatform.wiki.git`.

## Как опубликовать

1. Открыть <https://github.com/musicstashall/GlassPlatform/wiki> и нажать
   **Create the first page** → `Home` (текст можно вставить готовый).
   Это единственный шаг, который нельзя сделать через API.
2. Дальше страницы правятся обычным git:

```bash
git clone https://github.com/musicstashall/GlassPlatform.wiki.git
cp docs/wiki/*.md GlassPlatform.wiki/
cd GlassPlatform.wiki && git add . && git commit -m "wiki: диаграммы архитектуры" && git push
```

3. Служебные страницы вики: `_Sidebar.md` (навигация) и `_Footer.md`
   (подпись, ссылки на сайт). Внутренние ссылки — `[[Имя страницы]]`.

## Что ограничено в GitHub Wiki

| Возможность | Статус |
|---|---|
| Markdown (GFM): таблицы, `<details>`, `<kbd>`, `<sub>` | ✅ |
| Mermaid: `flowchart`, `stateDiagram`, `sequenceDiagram`, `classDiagram`, `erDiagram` | ✅ рендерится нативно |
| SVG/PNG как изображение (`![...](файл.svg)`) | ✅, загружается в вики-репозиторий |
| `<script>`, `<style>`, `iframe`, `onclick`, `style=""`, классы, id | ❌ вырезается санитайзером |
| Своя тема/шрифты/анимация, клики по узлам, фильтры, симуляторы | ❌ |
| Ограничение размера блока Mermaid | ~50 КБ, крупные схемы могут не отрисоваться |

Отсюда рабочая схема: **структурные схемы — в вики через Mermaid**,
**интерактив и симуляторы — только на сайте**, со ссылкой «Открыть интерактивную
версию» под соответствующей диаграммой. 3D-стек слоёв экспортируется в SVG/PNG
из исходной страницы и кладётся рядом с диаграммой.

См. пример разметки — [Home.md](Home.md).
